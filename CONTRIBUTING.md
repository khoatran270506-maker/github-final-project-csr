# Contributing to Simple Interest Calculator

Thank you for your interest in contributing to the Simple Interest Calculator project!

## Contributions Welcome

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

We appreciate contributions that help improve the functionality, usability, documentation, and reliability of this project.

## How to Contribute

1. Fork the repository to your GitHub account.
2. Clone your forked repository to your local computer.
3. Create a new branch for your changes.
4. Make your improvements or fix any identified issues.
5. Test your changes to ensure the calculator works correctly.
6. Commit your changes with a clear and descriptive commit message.
7. Push your branch to GitHub.
8. Open a pull request describing your changes.

## Reporting Bugs

If you find a bug, please open a GitHub issue and provide:

- A clear description of the problem.
- Steps to reproduce the issue.
- The expected behavior.
- The actual behavior.
- Any relevant error messages.

## Code Guidelines

- Keep the Bash script simple, readable, and well organized.
- Use meaningful variable names.
- Add comments where necessary.
- Test the simple interest calculation before submitting changes.
- Avoid unnecessary changes to unrelated files.

## Pull Request Guidelines

Before submitting a pull request:

- Ensure your code works correctly.
- Review your changes for errors.
- Provide a clear explanation of your improvements.
- Follow the project's Code of Conduct.
- Be respectful when responding to feedback.

## Code of Conduct

All contributors are expected to follow the guidelines outlined in the CODE_OF_CONDUCT.md file.

Thank you for helping improve this project!
