# Simple Interest Calculator

This project provides a simple Bash script that calculates simple interest based on user input.

## Description

The Simple Interest Calculator allows users to calculate interest by entering the principal amount, annual interest rate, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

Where:
- Principal (P): The initial amount of money.
- Rate (R): The annual interest rate expressed as a percentage.
- Time (T): The investment or loan period in years.

## Example

Principal = 1000

Rate = 5%

Time = 2 years

Simple Interest = (1000 × 5 × 2) / 100 = 100

## How to Run

1. Clone the repository.
2. Open a terminal in the project directory.
3. Run `bash simple-interest.sh`.
4. Enter the principal, interest rate, and time period.
5. View the calculated simple interest.
